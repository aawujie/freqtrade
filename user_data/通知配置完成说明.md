## 🚀 快速开始

### 方式 1：使用 Telegram 通知

#### 步骤 1：获取 Telegram Bot Token 和 Chat ID

1. 在 Telegram 搜索 `@BotFather`，创建机器人获取 Token
2. 在 Telegram 搜索 `@userinfobot`，获取你的 Chat ID

#### 步骤 2：设置环境变量

```bash
# 在 .env 文件中添加
FREQTRADE__TELEGRAM__TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
FREQTRADE__TELEGRAM__CHAT_ID=987654321
```

#### 步骤 3：使用配置

```bash
docker compose run --rm freqtrade trade \
  -c /freqtrade/user_data/configs/config_base.json \
  -c /freqtrade/user_data/configs/config_telegram.json \
  -c /freqtrade/user_data/configs/config_pairs_futures.json \
  --strategy ichiV1
```

---

### 方式 2：使用 Webhook 通知（企业微信）

#### 步骤 1：创建企业微信机器人

在企业微信群中添加机器人，获取 Webhook URL

#### 步骤 2：设置环境变量

```bash
# 在 .env 文件中添加
FREQTRADE__WEBHOOK__URL=https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=YOUR_KEY
```

#### 步骤 3：使用配置

```bash
# 使用 Webhook 通知
docker compose run --rm freqtrade trade \
  -c /freqtrade/user_data/configs/config_base.json \
  -c /freqtrade/user_data/configs/config_webhook.json \
  --strategy ichiV1
```

## 🎨 自定义配置

### 自定义 Telegram 通知级别

编辑 `configs/config_telegram.json`:

```json
{
  "telegram": {
    "notification_settings": {
      "status": "silent",      // 静音
      "warning": "on",         // 开启
      "entry": "on",
      "entry_cancel": "off",   // 关闭（避免太频繁）
      "exit": "on"
    }
  }
}
```

### 自定义 Webhook 消息格式

编辑 `configs/config_webhook.json`:

```json
{
  "webhook": {
    "entry": {
      "content": {
        "text": "🟢 {pair} 买入\n价格: {limit:.2f}\n金额: {stake_amount:.2f} USDT"
      }
    }
  }
}
```

## 💡 最佳实践

### 1. 安全设置 🔒

```bash
# ✅ 使用环境变量（推荐）
export FREQTRADE__TELEGRAM__TOKEN="your_token"
export FREQTRADE__WEBHOOK__URL="your_url"

# ❌ 不要在配置文件中硬编码敏感信息
```

### 2. 通知分级 📊

**重要通知（建议开启）**：
- ✅ entry（买入信号）
- ✅ exit（卖出信号）
- ✅ warning（警告）
- ✅ protection_trigger（保护触发）

**可选通知**：
- ⚠️ entry_fill（买入成交）- 可能频繁
- ⚠️ exit_fill（卖出成交）- 可能频繁

**建议关闭（避免过于频繁）**：
- ❌ entry_cancel（买入取消）
- ❌ exit_cancel（卖出取消）
- ❌ status（状态更新）- 设为 silent

### 3. 消息格式建议 📝

**简洁格式**（适合移动端快速查看）：
```
BUY BTC/USDT @ 50000
100 USDT
```

**详细格式**（适合重要通知）：
```
🟢 买入信号
━━━━━━━━━━━━━━━
交易对: BTC/USDT
价格: 50000.00
投入: 100.00 USDT
策略: ichiV1
```

### 4. 多机器人管理 🤖

如果运行多个机器人：
- 使用不同的 `bot_name`
- 为每个机器人创建独立的 Telegram 群组
- 使用不同的 Webhook URL 或群组
