# 📢 通知配置说明

## 📁 通知配置文件

configs 文件夹中现在包含完整的通知配置模块：

```
configs/
├── config_telegram.json              ← Telegram 通知配置
├── config_telegram.json.example      ← Telegram 配置示例
└── config_webhook.json               ← Webhook 通知配置
```

## 🎯 配置文件说明

### 1. config_telegram.json - Telegram 通知

**功能**：
- ✅ 完整的 Telegram Bot 通知配置
- ✅ 支持所有通知类型
- ✅ 可自定义通知开关
- ✅ 使用环境变量保护敏感信息

**包含的通知类型**：
- 📊 状态更新（status）
- ⚠️ 警告信息（warning）
- 🚀 启动通知（startup）
- 🟢 买入通知（entry）
- ✅ 买入成交（entry_fill）
- ❌ 买入取消（entry_cancel）
- 🔴 卖出通知（exit）
- 💰 卖出成交（exit_fill）
- ❌ 卖出取消（exit_cancel）
- 🛡️ 保护触发（protection_trigger）

---

### 2. config_webhook.json - Webhook 通知配置

**功能**：
- ✅ 支持企业微信、钉钉、飞书等
- ✅ 详细的通知内容模板（中文友好）
- ✅ 包含所有事件类型
- ✅ 使用环境变量配置 URL
- ✅ 可根据需要删除或禁用特定通知

**支持的平台**：
- 企业微信机器人
- 钉钉机器人
- 飞书机器人
- 自定义 Webhook 服务

**自定义提示**：
- 💡 不需要某个通知？直接删除对应的配置项即可
- 💡 想要简化消息？修改 `content.text` 的内容
- 💡 只需要买卖通知？只保留 `entry` 和 `exit` 配置

## 🚀 使用方法

### 方案 1：使用 Telegram 通知

#### 步骤 1：获取 Telegram Bot Token 和 Chat ID

**获取 Bot Token**：
1. 在 Telegram 中搜索 `@BotFather`
2. 发送 `/newbot` 创建新机器人
3. 按提示设置名称（如：MyFreqtradeBot）
4. 获取 Token（格式：`123456789:ABCdefGHIjklMNOpqrsTUVwxyz`）

**获取 Chat ID**：
1. 在 Telegram 中搜索 `@userinfobot`
2. 向它发送任意消息
3. 获取你的 Chat ID（格式：`987654321`）

#### 步骤 2：设置环境变量

```bash
# 方式 1：在 .env 文件中添加
FREQTRADE__TELEGRAM__TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
FREQTRADE__TELEGRAM__CHAT_ID=987654321

# 方式 2：导出环境变量
export FREQTRADE__TELEGRAM__TOKEN="123456789:ABCdefGHIjklMNOpqrsTUVwxyz"
export FREQTRADE__TELEGRAM__CHAT_ID="987654321"
```

#### 步骤 3：使用配置

```bash
# 组合使用
docker compose run --rm freqtrade trade \
  -c /freqtrade/user_data/configs/config_base.json \
  -c /freqtrade/user_data/configs/config_secrets.json \
  -c /freqtrade/user_data/configs/config_telegram.json \
  -c /freqtrade/user_data/configs/config_pairs_futures.json \
  --strategy ichiV1
```

### 方案 2：使用 Webhook 通知（企业微信）

#### 步骤 1：创建企业微信机器人

1. 在企业微信群中添加机器人
2. 获取 Webhook URL（格式：`https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=YOUR_KEY`）

#### 步骤 2：设置环境变量

```bash
# .env 文件
FREQTRADE__WEBHOOK__URL=https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=YOUR_KEY

# 或导出
export FREQTRADE__WEBHOOK__URL="https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=YOUR_KEY"
```

#### 步骤 3：使用配置

```bash
# 使用 Webhook 通知
docker compose run --rm freqtrade trade \
  -c /freqtrade/user_data/configs/config_base.json \
  -c /freqtrade/user_data/configs/config_webhook.json \
  --strategy ichiV1
```

## 🎨 自定义通知消息

### Telegram 通知自定义

编辑 `config_telegram.json` 中的 `notification_settings`：

```json
{
  "telegram": {
    "notification_settings": {
      "status": "silent",      // silent: 静音通知
      "warning": "on",         // on: 开启
      "startup": "on",
      "entry": "on",
      "entry_cancel": "off",   // off: 关闭
      "entry_fill": "on",
      "exit": "on",
      "exit_cancel": "off",
      "exit_fill": "on"
    }
  }
}
```

### Webhook 消息自定义

编辑 `config_webhook.json` 中的消息模板：

```json
{
  "webhook": {
    "entry": {
      "msg_type": "text",
      "content": {
        "text": "🟢 买入 {pair}\n价格: {limit:.2f}\n金额: {stake_amount:.2f} USDT"
      }
    }
  }
}
```

### 可用变量

**交易相关**：
- `{pair}` - 交易对
- `{limit}` - 委托价格
- `{open_rate}` - 开仓价格
- `{close_rate}` - 平仓价格
- `{amount}` - 交易数量
- `{stake_amount}` - 投入金额
- `{stake_currency}` - 本位币（如 USDT）

**收益相关**：
- `{profit_amount}` - 收益金额
- `{profit_ratio}` - 收益比例
- `{profit_percent}` - 收益百分比

**时间相关**：
- `{date}` - 日期时间
- `{duration}` - 持仓时长

**其他**：
- `{status}` - 状态信息
- `{reason}` - 原因
- `{exit_reason}` - 退出原因

完整变量列表：[Freqtrade Webhook 文档](https://www.freqtrade.io/en/stable/webhook-config/)

## 💡 最佳实践

### 1. 安全设置

```bash
# ✅ 使用环境变量
export FREQTRADE__TELEGRAM__TOKEN="your_token"
export FREQTRADE__WEBHOOK__URL="your_webhook_url"

# ❌ 不要在配置文件中硬编码
# "token": "123456789:ABCdefGHI..."  # 不安全！
```

### 2. 通知分级

**重要通知（建议开启）**：
- ✅ entry（买入）
- ✅ exit（卖出）
- ✅ warning（警告）
- ✅ protection_trigger（保护触发）

**可选通知**：
- ⚠️ entry_fill（买入成交）- 频繁
- ⚠️ exit_fill（卖出成交）- 频繁
- ⚠️ status（状态）- 可能很多

**建议关闭**：
- ❌ entry_cancel（买入取消）- 太频繁
- ❌ exit_cancel（卖出取消）- 太频繁

### 3. 消息格式建议

**简洁格式**（适合移动端）：
```
BUY BTC/USDT @ 50000
Stake: 100 USDT
```

**详细格式**（适合桌面端）：
```
🟢 买入信号
━━━━━━━━━━━━━━━
交易对: BTC/USDT
价格: 50000.00
投入: 100.00 USDT
时间: 2024-09-30 12:00:00
策略: ichiV1
```

### 4. 多机器人管理

如果运行多个机器人，建议：
- 使用不同的 `bot_name`
- 创建不同的 Telegram 群组
- 使用不同的 Webhook URL

## 🔍 故障排除

### Telegram 连接失败

**问题**：无法连接 Telegram Bot

**解决**：
1. 检查 Token 是否正确
2. 检查 Chat ID 是否正确
3. 确认机器人已启动（向它发送 `/start`）
4. 检查网络连接（国内可能需要代理）

### Webhook 无响应

**问题**：Webhook 没有收到消息

**解决**：
1. 检查 Webhook URL 是否正确
2. 测试 URL 是否可访问
3. 检查消息格式是否符合平台要求
4. 查看 Freqtrade 日志中的错误信息

### 消息太频繁

**问题**：收到太多通知

**解决**：
1. 关闭 `entry_cancel` 和 `exit_cancel` 通知
2. 设置 `status` 为 `silent`
3. 调整策略参数，减少交易频率
