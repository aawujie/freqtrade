# 📁 Configs 文件夹使用说明

## ✅ 当前文件结构

```
user_data/
├── config_composed.json             ← 组合配置示例（保留在根目录）
├── config_backtest.json             
├── config_double_ma.json            
├── config_ichiV1.json              
└── configs/                         ← 模块化配置文件夹（所有模块都在这里）
    ├── README.md
    ├── 使用说明.md
    ├── config_base.json             ← 基础通用配置
    ├── config_secrets.json          ← 敏感信息（不提交Git）
    ├── config_secrets.json.example  ← 敏感信息示例模板
    ├── config_pairs_spot.json       ← 现货交易对配置
    └── config_pairs_futures.json    ← 合约交易对配置
```

## 🎯 设计思路

### 为什么这样组织？

1. **config_composed.json 在根目录**
   - ✅ 作为组合配置的入口点
   - ✅ 命令行使用更简洁：`-c user_data/config_composed.json`

2. **configs/ 文件夹存放所有模块**
   - ✅ 基础配置（base）统一管理
   - ✅ 敏感信息（secrets）独立管理
   - ✅ 交易对配置（pairs）按类型分离
   - ✅ 可扩展：未来可以添加更多模块
   - ✅ 结构清晰：所有可复用的配置都在一个地方

## 🚀 使用示例

### 1. 快速开始：使用预设组合

```bash
# 使用已经配置好的组合（合约交易 + ichiV1 策略）
freqtrade trade -c user_data/config_composed.json
```

`config_composed.json` 的内容：
```json
{
    "add_config_files": [
        "configs/config_base.json",          // 基础配置（configs 文件夹）
        "configs/config_secrets.json",       // 敏感信息（configs 文件夹）
        "configs/config_pairs_futures.json"  // 合约交易对（configs 文件夹）
    ],
    "strategy": "ichiV1"
}
```

### 2. 创建自定义组合：现货交易

在 `user_data/` 创建 `config_my_spot.json`:

```json
{
    "add_config_files": [
        "configs/config_base.json",
        "configs/config_secrets.json",
        "configs/config_pairs_spot.json"
    ],
    "strategy": "DoubleMAStrategy",
    "timeframe": "1h",
    "db_url": "sqlite:///trades_my_spot.sqlite"
}
```

运行：
```bash
freqtrade trade -c user_data/config_my_spot.json
```

### 3. 命令行灵活组合

```bash
# 方式1: 现货交易
freqtrade trade \
    -c user_data/configs/config_base.json \
    -c user_data/configs/config_secrets.json \
    -c user_data/configs/config_pairs_spot.json \
    --strategy DoubleMAStrategy

# 方式2: 合约交易
freqtrade trade \
    -c user_data/configs/config_base.json \
    -c user_data/configs/config_secrets.json \
    -c user_data/configs/config_pairs_futures.json \
    --strategy ichiV1
```

```

```

## 💡 路径规则

### 从根目录配置文件引用

如 `config_composed.json` 位于 `user_data/`:

```json
{
    "add_config_files": [
        "configs/config_base.json",            // configs 子文件夹
        "configs/config_secrets.json",         // configs 子文件夹
        "strategies/DoubleMAStrategy.json"     // 其他子文件夹
    ]
}
```

### 优先级规则

后面的配置会覆盖前面的同名参数：

```bash
freqtrade trade -c A.json -c B.json -c C.json
# 优先级：C > B > A
```

## ❓ 常见问题

### Q: 为什么所有模块配置都放在 configs/ 文件夹？

A: 统一管理所有可复用的配置模块，结构清晰，便于维护和扩展。根目录只保留组合配置文件。

### Q: 可以创建多个 secrets 文件吗？

A: 可以！比如创建 `config_secrets_test.json` 用于测试环境，`config_secrets_prod.json` 用于生产环境。

### Q: 如何快速切换不同的交易对组合？

A: 创建多个 pairs 配置文件，然后在组合配置中引用不同的文件即可。
