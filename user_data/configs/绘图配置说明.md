# 📊 绘图配置说明

## 📁 绘图配置文件

configs 文件夹中现在包含多个绘图配置文件，适用于不同的场景和策略：

```
configs/
├── config_plot.json              ← 通用绘图配置（完整指标）
├── config_plot_minimal.json      ← 最简配置（基础指标）
├── config_plot_double_ma.json    ← 双均线策略专用配置
└── config_plot_ichimoku.json     ← 一目均衡策略专用配置
```

## 🎯 配置文件说明

### 1. config_plot.json - 通用完整配置
包含最常用的技术指标：
- **主图**: SMA20/50, EMA50/100/200, 布林带
- **子图**: 成交量、RSI、MACD、随机指标

**适用场景**: 通用策略、多指标分析

### 2. config_plot_minimal.json - 最简配置
只显示核心指标：
- **主图**: EMA50, EMA200
- **子图**: 成交量、RSI

**适用场景**: 快速查看、性能优先

### 3. config_plot_double_ma.json - 双均线策略
针对 DoubleMAStrategy 优化：
- **主图**: 快线、慢线、趋势线、布林带
- **子图**: 成交量（含均线）、RSI、MACD

**适用场景**: DoubleMAStrategy 策略回测分析

### 4. config_plot_ichimoku.json - 一目均衡策略
针对 ichiV1 策略优化：
- **主图**: 一目均衡云图、转换线、基准线、8条趋势线
- **子图**: fan_magnitude、fan_magnitude_gain

**适用场景**: ichiV1 策略回测分析

## 🚀 使用方法

### 基础用法

```bash
# 使用通用配置绘图
freqtrade plot-dataframe \
  --config user_data/configs/config_plot.json \
  --strategy DoubleMAStrategy \
  --pairs BTC/USDT

# Docker 方式
docker compose run --rm freqtrade plot-dataframe \
  --config /freqtrade/user_data/configs/config_plot.json \
  --strategy DoubleMAStrategy \
  --pairs BTC/USDT
```

### 策略专用配置

#### 双均线策略绘图
```bash
docker compose run --rm freqtrade plot-dataframe \
  --config /freqtrade/user_data/configs/config_plot_double_ma.json \
  --strategy DoubleMAStrategy \
  --pairs BTC/USDT \
  --timerange 20240901-20240930
```

#### 一目均衡策略绘图
```bash
docker compose run --rm freqtrade plot-dataframe \
  --config /freqtrade/user_data/configs/config_plot_ichimoku.json \
  --strategy ichiV1 \
  --pairs BTC/USDT:USDT \
  --timerange 20240901-20240930
```

### 组合使用多个配置

```bash
# 基础配置 + 绘图配置
docker compose run --rm freqtrade plot-dataframe \
  -c /freqtrade/user_data/configs/config_base.json \
  -c /freqtrade/user_data/configs/config_secrets.json \
  -c /freqtrade/user_data/configs/config_pairs_spot.json \
  -c /freqtrade/user_data/configs/config_plot.json \
  --strategy DoubleMAStrategy \
  --pairs BTC/USDT
```

## 📋 常用绘图命令

```bash
docker compose run --rm freqtrade plot-dataframe \
  --config /freqtrade/user_data/configs/config_plot.json \
  --strategy DoubleMAStrategy \
  --pairs BTC/USDT \
  --timerange 20240901-20240930
```

### 2. 绘制多个交易对
```bash
docker compose run --rm freqtrade plot-dataframe \
  --config /freqtrade/user_data/configs/config_plot.json \
  --strategy DoubleMAStrategy \
  --pairs BTC/USDT ETH/USDT SOL/USDT \
  --timerange 20240901-20240930
```

### 3. 指定输出目录
```bash
docker compose run --rm freqtrade plot-dataframe \
  --config /freqtrade/user_data/configs/config_plot.json \
  --strategy DoubleMAStrategy \
  --pairs BTC/USDT \
  --plot-dir /freqtrade/user_data/plot \
  --timerange 20240901-20240930
```

### 4. 包含买卖信号
```bash
docker compose run --rm freqtrade plot-dataframe \
  --config /freqtrade/user_data/configs/config_plot.json \
  --strategy DoubleMAStrategy \
  --pairs BTC/USDT \
  --indicators1 fast_ma,slow_ma \
  --indicators2 rsi \
  --timerange 20240901-20240930
```

### 5. 绘制回测结果的盈利图
```bash
docker compose run --rm freqtrade plot-profit \
  --config /freqtrade/user_data/config_composed.json \
  --strategy DoubleMAStrategy \
  --timerange 20240901-20240930
```

## 🎨 自定义绘图配置

### 配置结构

```json
{
  "exchange": {
    "name": "binance"
  },
  "plot_config": {
    "main_plot": {
      "指标名称": {
        "color": "颜色",
        "type": "line|bar",
        "fill_to": "填充到的指标",
        "fill_color": "填充颜色"
      }
    },
    "subplots": {
      "子图名称": {
        "指标名称": {
          "color": "颜色",
          "type": "line|bar"
        }
      }
    }
  }
}
```

### 常用颜色

| 颜色 | 代码 | 示例 |
|------|------|------|
| 蓝色 | `"blue"` | 快线 |
| 红色 | `"red"` | 慢线 |
| 橙色 | `"orange"` | EMA |
| 紫色 | `"purple"` | RSI |
| 灰色 | `"#888888"` | 趋势线 |
| 半透明蓝 | `"rgba(100,100,255,0.4)"` | 成交量 |

### 示例：添加新指标

```json
{
  "plot_config": {
    "main_plot": {
      "my_indicator": {
        "color": "green",
        "type": "line"
      }
    },
    "subplots": {
      "My Custom Subplot": {
        "my_subplot_indicator": {
          "color": "purple",
          "type": "bar",
          "plotly": {
            "opacity": 0.5
          }
        }
      }
    }
  }
}
```

## 💡 实用技巧

### 1. 快速切换配置
```bash
# 使用环境变量或别名
alias plot-minimal="docker compose run --rm freqtrade plot-dataframe --config /freqtrade/user_data/configs/config_plot_minimal.json"
alias plot-full="docker compose run --rm freqtrade plot-dataframe --config /freqtrade/user_data/configs/config_plot.json"

# 使用
plot-minimal --strategy DoubleMAStrategy --pairs BTC/USDT
```

### 2. 批量绘图脚本
```bash
#!/bin/bash
PAIRS=("BTC/USDT" "ETH/USDT" "SOL/USDT")
STRATEGY="DoubleMAStrategy"
TIMERANGE="20240901-20240930"

for pair in "${PAIRS[@]}"; do
  echo "绘制 $pair..."
  docker compose run --rm freqtrade plot-dataframe \
    --config /freqtrade/user_data/configs/config_plot_double_ma.json \
    --strategy $STRATEGY \
    --pairs $pair \
    --timerange $TIMERANGE
done
```

### 3. 在 Jupyter Notebook 中使用
```python
# Cell 1: 导入并绘图
import subprocess

def plot_dataframe(strategy, pairs, timerange, config="config_plot.json"):
    """快速绘图函数"""
    cmd = [
        "docker", "compose", "run", "--rm", "freqtrade", "plot-dataframe",
        "--config", f"/freqtrade/user_data/configs/{config}",
        "--strategy", strategy,
        "--pairs", pairs,
        "--timerange", timerange
    ]
    subprocess.run(cmd)
    print(f"✅ {pairs} 绘图完成！")

# 使用
plot_dataframe("DoubleMAStrategy", "BTC/USDT", "20240901-20240930", "config_plot_double_ma.json")
```

## 🔧 常见问题

### Q: 绘图时提示缺少数据？
A: 先运行 `download-data` 下载数据：
```bash
docker compose run --rm freqtrade download-data \
  --config /freqtrade/user_data/configs/config_base.json \
  --timerange 20240901-20240930 \
  --timeframe 5m
```

### Q: 如何只显示特定指标？
A: 使用 `--indicators1` 和 `--indicators2` 参数：
```bash
docker compose run --rm freqtrade plot-dataframe \
  --config /freqtrade/user_data/configs/config_plot.json \
  --strategy DoubleMAStrategy \
  --pairs BTC/USDT \
  --indicators1 fast_ma,slow_ma \
  --indicators2 rsi
```

### Q: 绘图速度慢？
A: 使用最简配置或减少时间范围：
```bash
# 使用最简配置
--config /freqtrade/user_data/configs/config_plot_minimal.json

# 减少时间范围
--timerange 20240901-20240907
```
