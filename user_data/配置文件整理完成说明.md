## 🎯 设计理念

### 模块化设计
- **configs/** 文件夹：存放所有可复用的配置模块
  - 基础配置（config_base.json）
  - 敏感信息（config_secrets.json）
  - 交易对列表（config_pairs_*.json）
  
- **根目录**：存放完整配置和组合配置
  - 完整配置：如 config_double_ma.json（包含所有参数）
  - 组合配置：如 config_composed.json（引用模块组合）

## 🚀 快速使用

### 方法1：使用组合配置（推荐）⭐

```bash
# 直接运行预设的组合配置
freqtrade trade -c user_data/config_composed.json
```

`config_composed.json` 会自动引用：
- `configs/config_base.json` - 基础参数
- `configs/config_secrets.json` - API密钥
- `configs/config_pairs_futures.json` - 合约交易对

### 方法2：命令行灵活组合

```bash
# 现货交易
freqtrade trade \
    -c user_data/configs/config_base.json \
    -c user_data/configs/config_secrets.json \
    -c user_data/configs/config_pairs_spot.json \
    --strategy DoubleMAStrategy

# 合约交易
freqtrade trade \
    -c user_data/configs/config_base.json \
    -c user_data/configs/config_secrets.json \
    -c user_data/configs/config_pairs_futures.json \
    --strategy ichiV1
```

### 方法3：使用原有完整配置

```bash
# 原有配置保持不变，可以继续使用
freqtrade trade -c user_data/config_double_ma.json
freqtrade trade -c user_data/config_ichiV1.json
```

## ✨ 创建自定义组合

在 `user_data/` 根目录创建新配置，例如 `config_my_spot.json`：

```json
{
    "$schema": "https://schema.freqtrade.io/schema.json",
    "_comment": "我的现货策略配置",
    
    "add_config_files": [
        "configs/config_base.json",
        "configs/config_secrets.json",
        "configs/config_pairs_spot.json"
    ],
    
    "strategy": "DoubleMAStrategy",
    "timeframe": "1h",
    "max_open_trades": 5,
    "stake_amount": 200,
    "db_url": "sqlite:///trades_my_spot.sqlite",
    "logfile": "logs/my_spot.log"
}
```

运行：
```bash
freqtrade trade -c user_data/config_my_spot.json
```

## 📋 配置优先级

使用多个配置文件时，后面的会覆盖前面的：

```bash
freqtrade trade -c A.json -c B.json -c C.json
# 优先级：C > B > A
```

示例：
```bash
freqtrade trade \
    -c user_data/configs/config_base.json \        # 基础参数
    -c user_data/configs/config_secrets.json \     # API密钥
    -c user_data/configs/config_pairs_spot.json \  # 交易对
    -c user_data/config_my_override.json           # 自定义覆盖
```

## ❓ 常见问题

### Q: 为什么把配置分离到 configs/ 文件夹？
A: 
- ✅ 统一管理可复用的配置模块
- ✅ 敏感信息独立，便于安全管理
- ✅ 灵活组合，避免重复配置
- ✅ 结构清晰，易于维护和扩展

### Q: 原有的完整配置还能用吗？
A: 
- ✅ 可以！所有原有配置（config_double_ma.json、config_ichiV1.json等）都保持不变
- ✅ 你可以继续使用它们，也可以逐步迁移到模块化配置

### Q: config_secrets.json 会被提交到Git吗？
A: 
- ❌ 不会！已经添加到 `.gitignore`
- ✅ 只有 `config_secrets.json.example` 会提交，作为模板参考

### Q: 如何切换不同的策略？
A: 
```bash
# 方式1: 创建不同的组合配置文件
freqtrade trade -c user_data/config_strategy_a.json
freqtrade trade -c user_data/config_strategy_b.json

# 方式2: 使用 --strategy 参数
freqtrade trade -c user_data/config_composed.json --strategy DoubleMAStrategy
```
