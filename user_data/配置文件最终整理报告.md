## 🚀 使用示例

### 1. 双均线策略（现货）

```bash
# 使用新的模块化配置

  -c user_data/configs/config_base.json \
  -c user_data/configs/config_secrets.json \
  -c user_data/configs/config_pairs_spot.json \
  -c user_data/configs/config_telegram.json \
  --strategy DoubleMAStrategy
```
