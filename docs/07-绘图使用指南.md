## 绘图使用指南（Plotly 可视化）

本章介绍如何用 Freqtrade 的绘图命令生成交互式 Plotly 图表（HTML），包含 K 线、指标、买卖点与资金曲线等。

### 1. 何时用绘图命令

- `plot-dataframe`：基于策略规则在指定 timeframe/timerange 上“重算信号并出图”，或叠加数据库中的真实成交点。
- `plot-profit`：基于交易数据库绘制资金曲线/收益分布等。

> 与 Web UI 的轻量图不同，Plotly 图读取 `plot_config`，可绘制自定义指标、多子图与更丰富样式。

### 2. 前置要求

- Docker 镜像使用 `freqtradeorg/freqtrade:develop_plot`（已在本项目的 `docker-compose.yml` 配置）。
- 历史数据位于 `user_data/data/<exchange>/...`（可用 `download-data` 预下载）。
- 可选：交易数据库（dry-run/实盘）位于 `user_data/*.sqlite`。

### 3. 绘图专用配置（可选，推荐分离）

项目已提供示例 `user_data/config_plot.json`（只包含最小字段与 `plot_config`）。你也可以把绘图样式放在任意交易配置里，再在命令行合并使用。

示例（节选）：
```json
{
  "$schema": "https://schema.freqtrade.io/schema.json",
  "exchange": { "name": "binance" },
  "plot_config": {
    "main_plot": {
      "sma20": { "color": "blue" },
      "ema50": { "color": "orange" }
    },
    "subplots": {
      "RSI": { "rsi": { "color": "red" } },
      "MACD": {
        "macd": { "color": "blue" },
        "macdsignal": { "color": "red" },
        "macdhist": { "type": "bar", "plotly": { "opacity": 0.9 } }
      }
    }
  }
}
```

提示：绘图会尝试从策略 DataFrame 中寻找与 `plot_config` 同名的列；若策略未输出该列，则不会显示。

### 4. 常用命令

1) 理论买卖点（按策略重算）
```bash
docker compose -f /Users/apple/code/freqtrade/docker-compose.yml run --rm freqtrade \
  plot-dataframe --strategy ichiV1 \
  --config /freqtrade/user_data/config_plot.json \
  --pairs BTC/USDT --timeframe 5m --timerange 20250101-20250131
```

2) 真实买卖点（叠加数据库成交）
```bash
docker compose -f /Users/apple/code/freqtrade/docker-compose.yml run --rm freqtrade \
  plot-dataframe --strategy ichiV1 \
  --config /freqtrade/user_data/config_ichiV1.json \
  --config /freqtrade/user_data/config_plot.json \
  --db-url sqlite:////freqtrade/user_data/trades_ichiV1.sqlite \
  --pairs BTC/USDT --timeframe 5m --timerange 20250101-20250131
```

3) 资金曲线（基于数据库）
```bash
docker compose -f /Users/apple/code/freqtrade/docker-compose.yml run --rm freqtrade \
  plot-profit \
  --config /freqtrade/user_data/config_ichiV1.json \
  --db-url sqlite:////freqtrade/user_data/trades_ichiV1.sqlite
```

4) 多配置合并（后者覆盖前者）
```bash
... plot-dataframe --strategy ichiV1 \
  --config /freqtrade/user_data/config_ichiV1.json \
  --config /freqtrade/user_data/config_plot.json \
  --pairs BTC/USDT --timeframe 5m
```

5) 临时指定指标（不依赖 plot_config）
```bash
... plot-dataframe --indicators1 rsi macd macdsignal --indicators2 volume
```

输出位置：`user_data/plot/*.html`（双击即可用浏览器打开，支持缩放/隐藏曲线/十字光标等交互）。

### 5. 参数说明速查

- `--pairs`：交易对，多个用空格分隔（建议单对单图）。
- `--timeframe`：K 线周期（若与数据/策略不一致，会自动重算）。
- `--timerange`：时间区间；如 `20250101-20250131`，或 `-30d` 表示最近 30 天。
- `--db-url`：交易数据库（如 `sqlite:////freqtrade/user_data/trades_ichiV1.sqlite`）。
- `--indicators1/--indicators2`：主图/副图临时指标。

### 6. 常见问题

- 看不到自定义指标？
  - 策略需在 DataFrame 中输出同名列；否则 `plot_config` 里声明也画不出来。
  - 可先用 `--indicators1/2` 验证该列名是否存在。

- 图为空或数据很短？
  - 检查本地历史数据是否下载到 `user_data/data/<exchange>/<pair>/<timeframe>`。
  - `--timerange` 是否超出已有数据范围。

- 跟 Web UI 的图有什么区别？
  - Web UI 图轻量且不读取 `plot_config`；Plotly 图可高度自定义并离线查看。

### 7. 进阶技巧

- 建议把绘图样式放入独立文件（如 `config_plot.json`），与交易配置分离；命令行通过 `--config` 合并。
- 需要基于“真实成交”出图时，务必传入 `--db-url`；否则是“按策略理论信号”重算的买卖点。
